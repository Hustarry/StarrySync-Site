StarrySync Vault 同步使用说明

日常笔记库：D:\obsidianVault\StarrySync Vault。

原始初始库：D:\obsidianVault\Obsidian Vault，保留迁移时的内容，不参与这套 Git 同步。迁移前的完整 ZIP 位于 D:\obsidianVault-Backups。

GitHub 私人仓库：https://github.com/Hustarry/StarrySync-Vault

日常操作

  1. 打开 StarrySync Vault。Git 插件会在启动时拉取。
  2. 编辑笔记、粘贴图片。新附件存入 image，链接使用 Markdown 相对路径。
  3. 需要立即保存到 GitHub，按 Ctrl+P，运行 Git: Commit-and-sync。
  4. 换电脑前手动同步一次；另一台电脑先 Pull，再开始编辑。避免两台设备同时编辑同一篇笔记。

每 10 分钟的自动同步仅在 Obsidian 打开且插件已启用时运行。网络中断时本地内容仍保留，恢复网络后再次同步。出现冲突时先保留两端内容，暂停自动同步，再检查和合并；不要直接覆盖或强制推送。

同步范围

同步笔记、图片、常规库设置、插件启用列表和 Git 插件程序。工作区、回收站及插件 data.json 保留在设备本地，因此换机后需要重新配置插件自动同步周期。

凭据由 Windows Credential Manager 保存，不放入笔记或 Git 仓库。此库单独使用当前用户目录下的 Git Credential Manager 3.0.2。

换电脑

安装 Obsidian 和 Git，克隆私人仓库后作为本地库打开。完成 GitHub 登录，检查并启用已知来源的 Git 插件。先手动 Pull 和 Commit-and-sync 验收，再设置 10 分钟自动同步。不要让其他同步工具同时写入此库。

本段从独立克隆目录提交，用于验证当前笔记库能够从 GitHub 拉取另一设备产生的修改。
